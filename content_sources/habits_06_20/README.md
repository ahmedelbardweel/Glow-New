# مصادر بكج العادات ٦–٢٠

الملفات النصية هنا نسخة من السكربتات المقدمة، تشمل الحوارات وأسئلة كل عادة. `prepared.json` هو ناتج تحليل المصادر قبل توليد الصوت؛ حقل حالته يخص مرحلة التحضير فقط.

لبناء الصوت والبيانات بعد ضبط `ELEVENLABS_API_KEY` في بيئة التشغيل:

```powershell
node tools/voice/build_habits_pack_2.mjs content_sources/habits_06_20
```

المخرجات: أربعة ملفات `assets/content/habits2_*.json`، وملفات MP3 للعادات ٦–٢٠ ضمن `assets/voice/habits/`، وخريطة `bundled_habit_audio.g.dart`. الأصوات المخبأة في مجلد أدوات التوليد ليست ملفات التشغيل؛ ملفات MP3 النهائية هي التي تُرفق بالتطبيق.

شغّل `supabase/habits_pack_2.sql` بعد سكيمة الإدارة إن لم يكن مطبقاً. عند فتح صفحة بكجات الأدمن في النسخة الجديدة، يُنشأ البكج كمسودة. يحتاج المستخدمون نسخة التطبيق التي تتضمن هذه الأصوات لتشغيلها محلياً؛ نشر المسودة وحده لا يضيف ملفات الصوت إلى نسخة قديمة من التطبيق.

للتحقق من المحتوى النهائي، شغّل `test/habits_pack_two_test.dart`، وللمكافآت المحلية شغّل `test/local_rewards_test.dart`.
